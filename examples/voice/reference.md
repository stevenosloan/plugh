# Reference

### The same shape for every entry

Each command gets the same headings in the same order: what it does in one line, usage, flags, examples, and exit codes.

Why: a regular reader learns the shape once and then jumps straight to the part they need.
When unsure: copy the shape of the nearest finished entry.

### Complete beats friendly

List every flag, including the rarely used ones, with its default.

Why: reference is where people go when the guide wasn't enough. A missing flag sends them to the source code.

### Lead with the fact

Start each flag's description with what it does: "Skips files matching the pattern." No "This flag allows you to...".

Why: readers scan the first few words of each line.
